We assessed the plausibility of additivity by examining whether study-specific effect estimates were consistent across trial designs that, under an additive model, estimate the same contrast (Pompoli et al., 2018; Ostinelli et al., 2025).
I. Additivity implies that studies comparing A + B versus B estimate the same 
relative effects as studies comparing A + C versus C
II. Additivity implies that a study comparing A versus B estimates the same relative 
component effects with a study that compares A + C versus B + C.
