We used the Cochrane Risk of Bias 2 (RoB 2) tool (https://www.riskofbias.info/welco
me/rob-2-0-tool/current-version-of-rob-2) to assess risk of bias for each study contributing data to a primary outcome. We made separate judgements for postintervention clinician-rated depressive symptoms, postintervention self-rated depressive symptoms, and acceptability (all-cause discontinuation).
